# Open source licenses

SealCode includes third-party software and adapted assets. To read their license and attribution
notices:

- Open **Settings → General**, find **Open source licenses** under **About**,
  and select **View licenses**.

The page lists the version when available, license identifier, and the parts of SealCode that include
or use the item. This also covers optional device tools that SealCode installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.
