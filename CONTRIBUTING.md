# Contributing to Harp

Thanks for wanting to help. Harp is early and changes quickly, so **we are not accepting pull
requests yet**. Pull requests may be closed without review. This will change once the project
settles; watch the repository to hear about it.

## What helps right now

- **Bug reports.** Use the bug report form. Include your Harp version (Settings → General), the
  steps to reproduce, and what you expected. For Roblox issues, say which Studio connection you use
  and attach the Studio output if relevant.
- **Ideas.** Use the feature request form. Describe the game development problem first, then the
  idea. Ideas for Roblox Studio, Blender and UEFN are especially welcome.
- **Security problems.** Report them privately; see [SECURITY.md](.github/SECURITY.md).

## Building from source

See [Run from source](README.md#run-from-source) in the README and
[docs/internals/overview.md](docs/internals/overview.md).

## Upstream

Harp is built on [T3 Code](https://github.com/pingdotgg/t3code). Fixes that are not specific to
Harp belong upstream; follow T3 Code's own contributing guide there.
